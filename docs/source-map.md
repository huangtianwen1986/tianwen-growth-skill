# 方法来源与版本边界

核对日期：2026-11-06。当前版本依据黄天文《引爆用户增长》新书分享讲义（80 页 PDF）及公开资料整理。作者已明确同意先用 PDF 制作首版；尚未完成原书全文逐章对照。

## 讲义到 Skill 的映射

页码为 PDF 物理页码，不是书籍页码。原始讲义不随仓库分发。

| 讲义位置 | 原有方法主题 | 本版转化 |
| --- | --- | --- |
| 第 43–48 页 | 七个增长驱动因素、供需与用户 | 按证据选择诊断方向，检查供给与承接 |
| 第 49、74–75 页 | 生命周期、价值、成本 | 明确周期，检查收入与成本，避免扩大亏损 |
| 第 52–56 页 | 从业务拆指标，分析并复盘 | 校验批次、漏斗口径，提出可验证解释 |
| 第 65–70 页 | 外部条件、看不见的漏斗 | 检查用户进入可见数据前的门槛 |
| 第 76 页 | 增长的组织责任 | 明确负责人、决策权和可控试验范围 |

本版新增：结构化诊断卡、实验比较与停止条件、数据归属标识、工具使用边界、合成场景核查。这些是把方法做成 Skill 的设计，不冒称原书逐字内容。

旧行业例子的渠道规则、金融产品条件和历史效果数字没有转成当前执行参数。私人材料、读者群截图和第三方全文没有进入仓库。
